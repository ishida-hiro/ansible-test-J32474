## 冪等性について

すべてのロールは繰り返し実行できるよう実装しています。

- レジストリ・サービス・ユーザ等は Ansible モジュールの冪等性に依存
- FTP 構成は PowerShell スクリプト内で現在値と比較し、差分がある場合のみ変更
- ドメイン参加 / DC 昇格は事前に `Win32_ComputerSystem` の状態を確認してスキップ
- `win_feature` は `state: present` のため、既に導入済みの役割・機能は changed にならない
- `win_user` は `update_password: on_create` のため、既存ユーザのパスワードは上書きしない

なお、以下は実行のたびに変化する可能性があります。

- `win_update`: 新しい更新プログラムが公開されると changed になる
- `win_ntp`: `w32tm /resync` は毎回実行（`changed_when: false` で changed 扱いにしない）
